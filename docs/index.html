FloridaFlip

2.1M+ propriedades analisadas

Next.js DuckDB Parquet Google Maps Python Recharts +6
Ver projeto Código
Detalhes do projeto
Problema resolvido Investidores imobiliários perdem horas cruzando dados de dezenas de fontes públicas para encontrar boas oportunidades. O FloridaFlip agrega tudo — avaliações, vendas, aluguéis, risco de enchente, seguros — em um painel único com sinais automáticos de oportunidade.

Funcionalidades

  • Mapa interativo dos 67 condados com choropleth por métrica (preço, estoque, dias no mercado)
  • Busca em 2.1M propriedades via DuckDB/Parquet com filtros e sinais automáticos
  • Calculadora de flip/hold/BRRRR com custos de fechamento e seguro da Flórida
  • Scoring multidimensional de submercados por ZIP code (9 dimensões)
  • Dashboard executivo com KPIs, tendências e geração de relatório PDF

Capacidades demonstradas

  • Ingestão e normalização de dados públicos heterogêneos (FDOR, FEMA, Census ACS, Redfin)
  • Consultas analíticas sobre milhões de registros no browser usando DuckDB + Parquet
  • Modelagem financeira domain-specific com regras regulatórias locais
  • Visualização geoespacial interativa com polígonos e drill-down
  • Scoring multidimensional com pesos configuráveis para ranqueamento
