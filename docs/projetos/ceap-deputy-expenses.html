CEAP Dashboard — Transparencia Parlamentar

Cidadaos, jornalistas e orgaos de controle nao conseguem cruzar dados de despesas parlamentares (CEAP) com emendas orcamentarias para identificar padroes suspeitos. O dashboard aplica metodos estatisticos (Benford, HHI, mismatch de CNAE) sobre 660 mil+ transacoes e entrega sinais de risco prontos para investigacao.

Ver projeto Codigo

Funcionalidades

O que o CEAP Dashboard faz

  • Dashboard com visao geral de R$ 686M em gastos de 847 deputados com KPIs, filtros e ranking
  • Perfil individual de deputado com metricas de Benford, HHI, valores redondos e red flags automaticos
  • Analise de concentracao de fornecedores (HHI) por categoria de despesa com drill-down
  • Spotlight investigativo com cruzamento CEAP x Emendas (caso Operacao Overclean com pivot table interativa)
  • Deteccao de mismatch CNAE: empresas recebendo por servicos fora da sua atividade economica registrada
  • Pipeline de dados com coleta via API Dados Abertos, enriquecimento de CNPJ via OpenCNPJ/BrasilAPI, e armazenamento DuckDB
  • Analise por categoria de despesa (veiculos, divulgacao, combustivel) com benchmarks estatisticos

Arquitetura

Como funciona

Fontes

  • API Dados Abertos da Camara (CEAP)
  • Portal da Transparencia (Emendas)
  • OpenCNPJ / BrasilAPI (CNPJ, CNAE)

Pipeline

  • Ingestao e normalizacao com Python/pandas
  • Enriquecimento de CNPJ e CNAE
  • Analise estatistica (Benford, HHI, scipy)
  • Armazenamento DuckDB + JSON estatico

Produto

  • Dashboard React com visualizacoes D3.js
  • Perfis de deputados com red flags
  • Spotlight investigativo interativo
  • Deploy em Cloudflare Pages + Workers

Capacidades

O que isso demonstra

  • Ingestao massiva de dados governamentais heterogeneos via APIs publicas com normalizacao, deduplicacao e enriquecimento (CNPJ, CNAE, nomes parlamentares)
  • Aplicacao de metodos estatisticos de deteccao de fraude em dados reais (Lei de Benford, Indice HHI, analise de valores redondos, mismatch de atividade economica)
  • Cruzamento de bases de dados com schemas incompativeis usando fuzzy matching de nomes e normalizacao de identificadores
  • Dashboard analitico com visualizacoes D3.js, feature flags para launch faseado, lazy loading e deploy em CDN global
  • Pipeline de dados reproduzivel: coleta API → DuckDB → analise Python → JSON estatico → frontend React — sem servidor backend
