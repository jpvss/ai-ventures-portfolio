Kiiry Dashboard

Donos de usinas solares distribuidas no Brasil precisam prestar contas mensais a investidores sobre energia compensada, receitas e pagamentos. Hoje esse processo e manual, com planilhas cruzando dados da CEMIG e da plataforma de billing, sujeito a erros que afetam pagamentos reais a locadores e investidores.

Ver projeto Codigo

Funcionalidades

O que o Kiiry Dashboard faz

  • Relatorio mensal por usina com balanco de recebimento por UC (unidade consumidora), incluindo energia compensada, tarifas, receita locador e status de pagamento
  • Pipeline de calculo financeiro automatizado: ingestao de Excel (CEMIG + Cogni), calculo de tarifa compensavel dinamica (GD I/II), classificacao de inadimplencia e geracao de totais
  • Dashboard gerencial multi-usina com KPIs (receita total, inadimplencia %, energia injetada) e matriz MBR de todas as plantas por periodos
  • Geracao de PDF via WeasyPrint para relatorios de investidores e comissoes de vendedores com auditoria embutida
  • Trilha de auditoria completa: tooltips com formulas, JSON de auditoria por usina/mes, e painel de auditoria com diff entre valores Cogni e calculados

Arquitetura

Como funciona

Fontes

  • Excel CEMIG (compensacao de energia)
  • Cogni (faturas, boletos, UCs)
  • Configuracao TOML por usina

Pipeline

  • ETL Pandas multi-fonte
  • Calculo de tarifa compensavel GD I/II
  • Classificacao de inadimplencia
  • Validacao cruzada Pydantic v2

Produto

  • Dashboard gerencial multi-usina
  • Relatorios PDF para investidores
  • Trilha de auditoria completa
  • Matriz MBR plantas x periodos

Capacidades

O que isso demonstra

  • Modelagem financeira domain-specific com regras regulatorias do setor eletrico brasileiro (tarifas CEMIG, compensacao GD I/II, PIS/COFINS, ICMS, Fio B)
  • Pipeline de ETL robusto para dados heterogeneos de multiplas fontes (Excel CEMIG multi-aba, Cogni Faturas/Boletos/UCs) com normalizacao, aliasing e validacao cruzada
  • Geracao de documentos financeiros auditaveis com rastreabilidade completa de cada calculo (formulas, fontes, arredondamento) — compliance-ready
  • Arquitetura serverless-friendly com cache em memoria, zero banco de dados e deploy continuo via git push (Railway)
  • Gestao de status de pagamento multi-estado (PAGO, Inadimplente, Em Aberto, Nao Emitido, Inadimplente Anterior) com regras de negocio especificas do setor de energia solar
