CV10x

Profissionais de dados no Brasil nao sabem se o curriculo esta competitivo. Mandam candidaturas e nao recebem retorno, sem entender por que. O CV10x analisa o curriculo em 5 dimensoes, mostra exatamente o que melhorar, e no plano Pro reescreve cada secao com alternativas prontas para copiar e colar.

Ver projeto Codigo

Funcionalidades

O que o CV10x faz

  • Upload de curriculo (PDF/DOCX/TXT) com extracao de texto e analise por IA Claude em 5 dimensoes (Tecnico, Impacto, Estrutura, ATS, Narrativa) com score 0-100
  • Quick win gratuito com acao imediata de maior impacto, email gate para relatorio completo com 8-15 sugestoes priorizadas por dimensao
  • Relatorio Pro pago (via Hotmart) com reescrita personalizada de secoes do curriculo (opcoes A/B/C), sumario profissional, analise de keywords ATS, preparacao para entrevista e plano de acao
  • Sequencia de nurture emails automatizada (E1-E5) com cron jobs via GitHub Actions, fila Redis com dedup, e tracking de conversao por etapa
  • Job matching automatico para usuarios Pro: busca de vagas via SerpAPI, pre-filtro heuristico e ranking por LLM com categorias (destaque/encaixe/proximo passo)

Arquitetura

Como funciona

Fontes

  • Upload do usuario (PDF/DOCX/TXT)
  • SerpAPI (vagas de emprego)
  • Hotmart (pagamentos webhook)

Pipeline

  • Extracao de texto do curriculo
  • Analise por Claude com structured output (Zod)
  • Scoring em 5 dimensoes + sugestoes priorizadas
  • Fila de nurture em Redis com dedup

Produto

  • Quick win gratuito + email gate
  • Relatorio Pro com reescrita personalizada
  • Job matching automatico por LLM
  • Nurture emails + tracking Meta CAPI

Capacidades

O que isso demonstra

  • Integracao avancada com LLM (Claude) usando structured output com Zod schemas, prompt engineering iterativo com cache de sistema, retries e timeout handling em producao
  • Arquitetura de produto B2C completa com funil de conversao: free tier → email gate → nurture sequence → upsell Pro → pagamento (Hotmart webhook) → entrega automatica
  • Sistema de automacao de marketing end-to-end: cron jobs serverless (GitHub Actions), fila de nurture em Redis com dedup por hash, batch email via Resend, tracking server-side (Meta CAPI + Google Ads) e UTM attribution
  • Geracao dinamica de imagens OG (share cards) via @vercel/og com multiplos formatos (landscape, portrait, story, square) para compartilhamento em redes sociais
  • Operacao de produto digital em producao com rate limiting por IP, limites mensais por email, retry queues para falhas, idempotencia, e observabilidade via Vercel runtime logs

Oportunidades

O que podemos construir para voce

Projetos derivados que aplicam a mesma arquitetura para outros segmentos.

RH / Outplacement

Plataforma white-label de analise e otimizacao de curriculos para consultorias de carreira

Consultorias de outplacement revisam curriculos manualmente, gastando 2-4 horas por curriculo. Com demissoes em massa no setor de tech, o modelo manual nao escala. Precisam de analise inicial automatizada.

R$ 25k-45k 2-3 semanas

Educacao / EdTechs e bootcamps

Modulo de empregabilidade integrado a plataformas de ensino online

Bootcamps e cursos online prometem empregabilidade mas nao tem ferramenta objetiva para medir se o aluno esta pronto para o mercado. Um analisador de curriculo integrado ao LMS mostra progresso real.

R$ 30k-55k 3-4 semanas

Recrutamento / HRTechs e ATS

API de scoring e triagem automatizada de curriculos para plataformas de recrutamento

Plataformas ATS brasileiras recebem centenas de curriculos por vaga e usam keyword matching basico. Uma API de scoring multidimensional com feedback explicavel reduz tempo de triagem.

R$ 35k-65k 3-4 semanas

Governo / Programas de empregabilidade

Ferramenta de diagnostico e orientacao profissional para agencias de emprego (SINE/PAT)

O SINE e postos do trabalhador atendem milhoes de desempregados por ano com orientacao generica. Falta ferramenta para avaliar objetivamente o curriculo e direcionar para vagas compativeis.

R$ 40k-80k 4-5 semanas
