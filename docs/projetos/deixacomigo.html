DeixaComigo

Donos de carros usados premium (R$ 60-120K+) sao lowballados por lojistas que pagam 75-85% da FIPE. O DeixaComigo mostra a diferenca concreta entre vender para o lojista e consignar — com dados da FIPE em tempo real — e captura o lead do vendedor automaticamente para o corretor de consignacao.

Ver projeto Codigo

Funcionalidades

O que o DeixaComigo faz

  • Motor de avaliacao veicular com integracao FIPE (Parallelum v2) e cache em Supabase, comparando estimativa de lojista vs. valor de mercado vs. liquido de consignacao com faixas de preco
  • Algoritmo de precificacao com 6 fatores calibrados (marca, idade, km, condicao, demanda regional, comissao) e classificacao de aptidao para consignacao (ideal/viavel/marginal)
  • Formulario mobile-first com selecao cascata marca → modelo → ano via API FIPE, input de km formatado e selecao de condicao com micro-copy explicativo
  • Captura de lead integrada ao resultado da avaliacao com persistencia em Supabase e notificacao por email (Resend) ao corretor contendo dados do veiculo e avaliacao completa
  • SEO tecnico completo: sitemap.xml dinamico, robots.txt, OpenGraph image gerado via JSX, Schema.org WebApplication, meta tags e canonical URLs

Arquitetura

Como funciona

Fontes

  • API FIPE (Parallelum v2)
  • Input do usuario (marca, modelo, ano, km)
  • Parametros de mercado (spreads, comissoes)

Pipeline

  • Consulta cascata marca → modelo → ano
  • Algoritmo de precificacao com 6 fatores
  • Classificacao de aptidao para consignacao
  • Cache inteligente em Supabase

Produto

  • Comparativo lojista vs. consignacao
  • Captura de lead com notificacao Resend
  • SEO programatico para trafego organico
  • Deploy em Vercel (regiao GRU1)

Capacidades

O que isso demonstra

  • Modelagem de precificacao domain-specific com multiplos fatores calibrados por pesquisa de mercado (tabela FIPE, spreads de lojista, depreciacao por marca/idade/km) e guard rails contra overpromising
  • Integracao com APIs externas de dados publicos (FIPE/Parallelum) com camada de cache inteligente em banco de dados, fallback gracioso e validacao de dados
  • Funil de conversao completo — de ferramenta gratuita de valor a captura de lead qualificado com notificacao automatica — implementado como Server Actions com validacao Zod
  • Infraestrutura de produto real com Supabase (PostgreSQL + RLS policies + migrations), autenticacao, email transacional (Resend), e deploy em regiao GRU1 (Sao Paulo)
  • SEO tecnico programatico para geracao de trafego organico em escala: sitemap, robots, structured data, OpenGraph dinamico, e arquitetura preparada para centenas de paginas de modelo/ano
