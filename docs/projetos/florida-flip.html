FloridaFlip

Investidores imobiliarios perdem horas cruzando dados de dezenas de fontes publicas para encontrar boas oportunidades. O FloridaFlip agrega tudo — avaliacoes, vendas, alugueis, risco de enchente, seguros — em um painel unico com sinais automaticos de oportunidade.

Ver projeto Codigo

Funcionalidades

O que o FloridaFlip faz

  • Mapa interativo dos 67 condados com choropleth por metrica (preco, estoque, dias no mercado)
  • Busca em 2.1M propriedades via DuckDB/Parquet com filtros e sinais automaticos (high yield, below assessed, regra dos 70%)
  • Calculadora de flip/hold/BRRRR com custos de fechamento e seguro especificos da legislacao da Florida
  • Scoring multidimensional de submercados por ZIP code (9 dimensoes: vacancia, qualidade do inquilino, yield, risco)
  • Dashboard executivo com KPIs, tendencias, comparacao entre condados e geracao de relatorio PDF

Arquitetura

Como funciona

Fontes

  • FDOR (avaliacoes imobiliarias)
  • FEMA (risco de enchente)
  • Census ACS (dados demograficos)
  • Redfin (mercado imobiliario)

Pipeline

  • Ingestao e normalizacao Python
  • DuckDB + Parquet (2.1M registros)
  • Scoring multidimensional por ZIP
  • Modelagem financeira domain-specific

Produto

  • Mapa choropleth interativo
  • Calculadoras de investimento
  • Ranking de submercados
  • Relatorios PDF executivos

Capacidades

O que isso demonstra

  • Ingestao e normalizacao de dados publicos heterogeneos (FDOR, FEMA, Census ACS, Redfin) em pipeline Python reproduzivel
  • Consultas analiticas sobre milhoes de registros no browser e servidor usando DuckDB + Parquet sem banco de dados externo
  • Modelagem financeira domain-specific com regras regulatorias locais (seguro FL, custos de fechamento OIR, NFIP)
  • Visualizacao geoespacial interativa com poligonos, choropleth e drill-down por regiao
  • Scoring multidimensional com pesos configuraveis para ranqueamento e tomada de decisao
