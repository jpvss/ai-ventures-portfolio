# Engagement Pricing Framework

## Tiered Pricing Structure

### Tier 1 — Diagnostic/Audit (Entry Point)
- **Price range**: $5K-$15K
- **Scope**: Data maturity assessment, quick wins identification
- **Duration**: 2-4 weeks
- **Purpose**: Demonstrate capability, convert to larger engagements
- **Gateway offer**: R$10K Data Maturity Assessment (fixed-price, productized)

### Tier 2 — Implementation (Mid-Tier)
- **Price range**: $25K-$75K
- **Scope**: Data infrastructure build, automation deployment
- **Duration**: 4-12 weeks
- **Purpose**: Core revenue driver, builds case studies

### Tier 3 — Transformation (Enterprise)
- **Price range**: $75K-$200K+
- **Scope**: Full data stack transformation
- **Duration**: 3-6+ months
- **Purpose**: High-value engagements, deep client relationships

---

## Value-Based Pricing Principle

**Price on value created, not time spent.** If automation saves a client $500K/year, charging $100K (20% of value) delivers a 5x ROI. This is the fundamental unlock — AI breaks the link between time invested and value delivered.

### The Math
- AI-native delivery: 65-80% gross margins
- Traditional agency: 20-35% gross margins
- API costs for tasks requiring a $50K/year employee: $200-500/month
- AI handles 60-70% of production work

## R$10K Data Maturity Assessment — The Gateway Offer

The diagnostic/audit tool is the **core paid product** — the entry point that demonstrates capability and converts to larger engagements.

### What It Includes
- Score 6 capability dimensions on 1-5 scale:
  1. Data Strategy
  2. Data Governance
  3. Data Quality
  4. Data Infrastructure
  5. Analytics & AI Readiness
  6. Data Culture
- Interactive PDF with radar chart, dimension scores, prioritized recommendations
- Quick wins (30-day), medium-term (90-day), strategic (6-12 month) roadmap
- Executive presentation with locked 90-day implementation plan

### Conversion Path
R$10K Assessment → $25K-$200K Implementation Projects

**Productization opportunity**: Fixed-price, standardized delivery, repeatable across verticals with minimal customization.

## Pricing Evolution as You Scale

### Stage 1 — Project-Based (Now)
- Diagnostic: $5K-$15K
- Implementation: $25K-$75K
- Efficiency gains increase effective hourly rate
- Focus on building case studies and proving the model

### Stage 2 — Value-Based (Growth)
- Price on client ROI
- If automation saves $500K/year, charge $100K
- Requires demonstrated track record of outcomes
- Shift conversation from cost to investment

### Stage 3 — Retainer + Usage Hybrid (Scale)
- Monthly retainer: $5K-$25K/mo
- Plus usage-based platform features
- Predictable recurring revenue
- Deeper client relationships

### Stage 4 — SaaS Subscription (Platform)
- Self-service tiers with published pricing
- Services become premium add-on
- Target revenue split: 30% services / 70% product (by Month 18-36)
