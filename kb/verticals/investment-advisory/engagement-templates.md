# Investment Advisory — Engagement Templates

## Diagnostic Engagement (Paid Assessment)

**Price Range:** R$25,000–R$80,000
**Duration:** 2–3 weeks
**Deliverables:** Data Fragmentation Audit, Process Efficiency Metrics, Compliance Gap Analysis, Prioritized Opportunity Matrix, ROI Projections, Technology Architecture Recommendation

### Week-by-Week Breakdown

#### Week 1: Discovery

- **Stakeholder interviews**: Partners/owners, compliance officer, operations lead, and 2–3 senior advisors
- **Technology inventory**: Platform tools (XP Hub/CRM, BTG portal), portfolio consolidation (Gorila, SmartBrain, Comdinheiro), external CRM (HubSpot, Pipedrive), communication tools (WhatsApp Business, email)
- **Data flow mapping**: Document how data moves between 5–12 disconnected sources
- **Key process documentation**: Client onboarding, reporting cycles, rebalancing workflows, compliance checks

#### Week 2: Assessment

- **Data fragmentation quantification**: Count and classify all disconnected data sources (typical: 5–12)
- **Manual process audit**: Measure hours/week spent on report generation, portfolio monitoring, compliance checks, lead management, and client communications
- **Compliance gap analysis**: Evaluate against CVM 178/179, CVM 30 suitability requirements, LGPD data handling, and ANBIMA Código de Distribuição
- **Client engagement metrics**: Measure contact frequency per segment, NPS/satisfaction, churn rate, AuC growth per advisor
- **Revenue efficiency**: Calculate revenue per advisor, cost per client served, advisor capacity utilization

#### Week 3: Recommendations

- **Prioritized opportunity matrix**: Quick wins (<30 days) vs. strategic projects (3–6 months)
- **ROI projections** for top 3 opportunities
- **Technology architecture recommendation**: Platform-agnostic data infrastructure design
- **12-month implementation roadmap**

### Discovery Questions

1. How many data systems do your advisors touch daily? (Expect: 5–12)
2. How many hours per week does each advisor spend on report generation? (Expect: 6–10 hours)
3. What is your current churn rate? (Expect: 8–15%/year)
4. How do you track suitability compliance for CVM 30? (Expect: annual/ad hoc, often manual)
5. How are you handling CVM 179 disclosure requirements? (Expect: manual, partial compliance)
6. What percentage of your advisors consistently use CRM? (Expect: <50%)
7. How many clients does your average advisor manage? (Expect: 100–200)
8. What is your lead conversion rate? (Expect: 5–10%)
9. Do you have visibility into clients' assets at other institutions? (Expect: limited/none)
10. How do you currently segment clients for communication? (Expect: AuC tiers only, if any)

### Assessment Dimensions

| Dimension | What We Measure | Baseline (Typical) | Target |
|-----------|----------------|-------------------|--------|
| Report automation | Hours/week per advisor on reporting | 6–10 hrs/week | <30 min/week |
| Client contact frequency | Contacts per client per month | 1–2 | 4–6 (automated + personal) |
| Suitability compliance | Review cycle and method | Annual/ad hoc | Continuous monitoring |
| Lead conversion | Percentage of leads converted | 5–10% | 15–25% |
| Advisor capacity | Clients per advisor | 100–200 | 300–500 |
| Client retention | Annual churn rate | 8–15%/year | 4–8%/year |

## Implementation Engagements

### Implementation 1: Automated Client Reporting Dashboard

**Price Range:** R$150,000–R$300,000
**Duration:** 8–12 weeks
**Prerequisites:** Diagnostic completed; API access to primary platform (XP/BTG) and consolidation tools (Gorila/SmartBrain)
**Deliverables:** Automated data pipeline, AI-personalized client reports, performance attribution engine, benchmark comparison module, market commentary generator

#### Phase Breakdown
- **Weeks 1–2**: API integration (XP/BTG + Gorila/SmartBrain), data normalization layer
- **Weeks 3–5**: Report template engine, performance attribution logic, benchmark integration
- **Weeks 6–8**: AI personalization layer (market commentary, client-specific insights)
- **Weeks 9–10**: Advisor dashboard, delivery automation (email/WhatsApp)
- **Weeks 11–12**: Testing, advisor training, go-live

**Key outcome**: A 20-advisor escritório saves 320 hours/month — equivalent to 3–4 FTEs worth R$30K–R$80K/month redirected to client acquisition.

### Implementation 2: CRM Intelligence and Client Segmentation

**Price Range:** R$100,000–R$200,000
**Duration:** 6–10 weeks
**Prerequisites:** Diagnostic completed; CRM access; portfolio data pipeline (from Project 1 or existing)
**Deliverables:** Unified client data layer, AI segmentation model, "next best action" engine, advisor dashboard

#### Phase Breakdown
- **Weeks 1–2**: Data unification across CRM, portfolio, and communication channels
- **Weeks 3–4**: Segmentation model development (risk profiles, life stages, product affinity)
- **Weeks 5–6**: "Next best action" engine (e.g., "Client X has 60% fixed income, moderate profile, Selic dropping → suggest rebalancing")
- **Weeks 7–8**: Advisor dashboard and notification system
- **Weeks 9–10**: Testing, calibration, advisor training

### Implementation 3: Compliance and Suitability Automation

**Price Range:** R$200,000–R$350,000
**Duration:** 10–14 weeks
**Prerequisites:** Diagnostic completed; access to portfolio data and client profiles
**Deliverables:** Continuous suitability drift detector, CVM 179 disclosure generator, LGPD consent management system, regulatory reporting pipeline

### Implementation 4: Churn Prediction and Client Retention Engine

**Price Range:** R$120,000–R$250,000
**Duration:** 8–12 weeks
**Prerequisites:** Diagnostic completed; historical client behavioral data (12+ months preferred)
**Deliverables:** ML churn prediction model, early warning dashboard, retention playbooks, Pluggy Open Finance integration for external signals

### Implementation 5: Lead Scoring and Prospecting Intelligence

**Price Range:** R$80,000–R$150,000
**Duration:** 6–8 weeks
**Prerequisites:** Diagnostic completed; marketing data sources, CRM data
**Deliverables:** AI lead scoring model, prospecting dashboard, conversion optimization recommendations

## Engagement Arc (Full Journey)

```
Diagnostic → 1st Implementation → Expansion → Retainer
(R$25-80K)   (R$150-300K)         (R$100-350K)  (R$15-30K/mo)
  2-3 wks      8-12 wks            6-14 wks      Ongoing
```

**Typical sequence**: Diagnostic → Automated Reporting (highest ROI, fastest win) → CRM Intelligence or Compliance Automation → Churn Prediction → Lead Scoring

## Retainer Model

**Monthly Price:** R$15,000–R$30,000
**Includes:** Model monitoring and retraining, data pipeline maintenance, compliance rule updates (CVM/ANBIMA changes), quarterly performance review, priority support
**SLA:** 4-hour response for critical issues (compliance alerts), 24-hour for standard requests
