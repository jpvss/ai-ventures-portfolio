# LicitaLeads — Technical Architecture

## Tech Stack Choices and Rationale

- **Next.js 16 + React 19:** Full-stack framework with Server Components for data-heavy dashboard and API routes for pipeline scripts.
- **Static JSON (no database):** Zero-infrastructure approach for rapid market validation — pre-processed data served as static JSON files. Eliminates database costs and complexity during MVP phase.
- **Zod 4:** Runtime validation of API responses from PNCP and BrasilAPI — ensures data quality at ingestion boundaries.
- **Resend:** Transactional email for lead notifications and commission reports.
- **tsx:** TypeScript execution for data pipeline scripts (ingestion, enrichment, scoring) without separate build step.
- **Vercel free tier:** Zero-cost deployment for market validation.

## Data Architecture

- **Primary source:** PNCP API (Portal Nacional de Contratacoes Publicas) — public contracts, procurement data
- **Enrichment sources:** BrasilAPI (CNPJ data), Portal da Transparencia/CGU (CEIS/CNEP ineligibility lists)
- **Storage:** Static JSON files generated by pipeline scripts — no database
- **Pipeline:** Idempotent ingestion with circuit breaker, rate limiting, and resume-safety for API calls
- **Scoring:** Composite 0-100 score computed at pipeline time and stored in JSON

## Key Technical Patterns

- **Zero-infrastructure data product:** Static JSON + Vercel free tier for rapid B2B SaaS validation without database costs
- **Idempotent pipeline with circuit breaker:** Resume-safe data ingestion that handles API failures gracefully
- **Domain-specific scoring engine:** 4-dimension composite score (value, recency, contact, category) with tier classification
- **CNPJ enrichment pipeline:** Automated business data lookup with rate limiting — reusable for any Brazilian B2B product
- **High-density filter UI:** 11 combined filters with real-time KPI updates — pattern for data exploration dashboards

- Client-side filtering over pre-loaded datasets for responsive UX
- Pipeline runs as batch process — no real-time ingestion overhead
